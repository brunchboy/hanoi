Keyboard Navigation Tips

  • In addition to using the links at the bottom of each page, you can use the arrow keys, ← and →, to move to the previous or next slide.
  • For slides that have multiple steps, you in addition to clicking the Next button, you can press the return key.
  • You can open a Speaker Notes window by pressing home. That will update with notes, if any, for the current slide, as you navigate.
  • For slides that have multiple steps, the Speaker Notes window may provide notes for later steps, even if there are none for the first step.
  • After opening the Speaker Notes window, be sure to return focus to the slide window, or these navigation keys will not work.
