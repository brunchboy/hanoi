Moves Needed for Recursive Solution

  • The base case of a single ring requires one move.
  • In the recursive case of n rings, we have one recursive call to move n – 1 rings out of the way, a single move for the base ring, and then the same recursive call to move the other rings on top of it. So:
    hanoi_moves(n) = 2 × hanoi_moves(n – 1) + 1
  • n = 2: 2 × 1 + 1 = 3
    n = 3: 2 × 3 + 1 = 7
    n = 4: 2 × 7 + 1 = 15
    n = 5: 2 × 15 + 1 = 31
    Continuing: 63, 127, 255, 511, 1023…
  • In general, for n rings, 2n – 1 moves.
  • Notice that this, too, is a recursive function with a base case, and we were able to find a pattern and, thereby, a non-recursive solution.
