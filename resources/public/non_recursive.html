State Moves
           🐇 🐢  
  1. Determine how we move the smallest ring: count rings in the tower; if the count is…
    • Odd, we rotate it left: A, B, C, A, B, C…
    • Even, we rotate it left: A, C, B, A, C, B…
  2. Rotate the smallest ring.
  3. Check if we are done, is the tower moved to post B?
  4. If not, make the only legal move that does not involve the smallest ring, then go back to step 2.
